# Personal Portfolio - Assignment 2

Interactive portfolio website with dynamic features built for my web development course.

## 🚀 What I Built

This is the enhanced version of my portfolio from Assignment 1. I added interactive features to make it more engaging and functional.

### Features

**1. Time-Based Greeting**
- Shows different greetings based on what time it is
- Morning, afternoon, evening, or late night messages
- Updates automatically when you visit

**2. Smart Contact Form**
- Checks if your email is valid as you type
- Shows error messages if something's wrong
- Saves your draft automatically (uses localStorage)
- Character counter so you don't go over 500 characters
- Success message when you submit

**3. Smooth Animations**
- Sections fade in when you scroll to them
- Project cards lift up when you hover
- Smooth scrolling when clicking navigation
- Everything feels more polished

## 🛠️ Tech Stack

- HTML5
- CSS3 (animations, grid, flexbox)
- Vanilla JavaScript
- localStorage API
- Intersection Observer API
